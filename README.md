# Spicy Hemp (рабочее название)

Ручные горшки с пряными травами. На каждом горшке уникальный QR-код, который открывает «паспорт» растения: уход, параметры, проблемы, применение и связи по семействам. Каждый скан попадает в аналитику. В проект входит интернет-магазин.

**Статус: готово к тестированию (v0.1).** Работает без внешних сервисов; Notion, Supabase и платёжные системы подключаются через переменные окружения.

## Быстрый старт

```bash
cd apps/web
cp .env.example .env.local     # необязательно: без ключей работает локальный режим
npm install
npm run dev                    # http://localhost:3000
```

Локальный режим: данные (заказы, горшки, сканы) лежат в `apps/web/.data/store.json`, при первом запуске создаются демо-горшки по одному на каждое растение. Откройте `/admin/pots` (в dev без пароля), чтобы увидеть коды, и перейдите по `/p/<код>` как при сканировании QR.

Закрытая админка в production требует `ADMIN_PASSWORD`.

## Что внутри

| Часть | Где | Что делает |
|---|---|---|
| Сайт uk/en | `apps/web/src/app/[locale]` | главная, справочник (поиск, фильтры), паспорт растения, семейства, магазин, корзина, оформление, страница заказа, гайды, инфостраницы |
| QR вход | `apps/web/src/app/p/[code]` | проверка кода, запись скана, редирект на паспорт на нужном языке |
| Напоминание о поливе | `/api/reminder/[slug]` | `.ics` с повторяющимся событием, без регистрации |
| Магазин | `src/lib/shop*.ts`, `src/lib/orders.ts` | цены считаются на сервере; оплата при получении (Нова пошта), Stripe, LiqPay |
| Админка | `/admin` | аналитика сканов, заказы, партии горшков, выдача QR под заказ, печатный лист QR |
| Контент | `apps/web/src/data` + Notion sync | 15 трав на двух языках; синхронизация из Notion: `npm run sync:notion` |
| База | `supabase/migrations` | схема с RLS; в коде тонкий REST-клиент |

## Команды (в `apps/web`)

| Команда | Что делает |
|---|---|
| `npm run dev` / `build` / `start` | разработка / сборка / production |
| `npm run typecheck` | проверка типов |
| `npm test` | юнит-тесты (vitest) |
| `node tests/e2e/smoke.mjs` | сквозной тест в Chromium (сервер на `BASE`, по умолчанию :3100) |
| `npm run pots:generate -- basil 40 B-2026-10` | партия горшков с кодами (CSV в stdout) |
| `npm run sync:notion` | Notion → `src/data/generated/content.json` (+ Supabase) |

## Что намеренно не сделано

- Реальные фотографии (сейчас векторные иллюстрации), цены, юридические тексты: заглушки с пометкой «тестовые».
- Отправка e-mail (подтверждение заказа, напоминания): нужен Resend и домен.
- Реальные вызовы Stripe/LiqPay/Supabase/Notion не проверялись без ключей: подписи вебхуков и маппинг Notion покрыты юнит-тестами, остальное нужно проверить с тестовыми ключами (см. `docs/TESTING.md`).
