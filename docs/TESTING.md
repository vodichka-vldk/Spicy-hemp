# Тестирование (приёмочный чеклист)

## Автоматичні перевірки

```bash
cd apps/web
npm run typecheck     # типи
npm test              # 165 юніт-тестів: контент, коди, ціни, замовлення, платежі, Нова пошта, каталог, медіа, Telegram, нагадування, відгуки, питання, журнал, ліміти, міграції SQL (PGlite)
npm run e2e           # чиста збірка, чисте сховище, сервер, браузерні тести і аудит сайту (див. нижче)
```

`npm run e2e` (`scripts/e2e.sh`) сам збирає застосунок, запускає його на порту 3199 з тестовими змінними і виконує:

1. **`tests/e2e/smoke.mjs`**: сценарії в Chromium. Українська й англійська: редирект мови, пошук і фільтри, QR, `.ics`, кошик, валідація, замовлення (uk, накладений платіж; en, оплата карткою без ключа провайдера), сторінка замовлення, адмінка (вхід, партії, виділення QR, статуси, каталог, редактор, фото, CSV, питання, власники, журнал), Mini App з підписаним `initData` (активація, ім'я, журнал із фото, вкладки Сьогодні/Скан/Профіль), приватність фото, ліміт перебору кодів, заголовки безпеки, health, cron.
2. **`tests/e2e/audit.mjs`**: обходить усі досяжні сторінки (100 публічних, 13 сторінок адмінки) і перевіряє: статус < 400, помилки в консолі, горизонтальний скрол на 320/390/768/1280 px, доступність (axe, WCAG 2.1 AA, critical і serious).

Окремо: `BASE=http://localhost:3199 node tests/e2e/audit.mjs` проти будь-якого запущеного сервера.

## Що знайшов аудит і виправлено
| Де | Проблема | Виправлення |
|---|---|---|
| Усі сторінки на 320 px | Один широкий елемент розтягував сторінку за межі екрана (grid без `minmax(0,1fr)`) | Стеки й сітки можуть стискатися: правила в `globals.css` |
| Товар, паспорт @320 | Довгі підписи фактів («ТЕМПЕРАТУРА») виходили за плитку | Перенос слів у `FactTile` |
| Паспорт @320 | Рядок розділів із від'ємними відступами | Замінено на `sh-chiprow` |
| Адмінка @390 | Поле вибору файлу ширше за картку | `input[type=file]` стискається |
| Нова пошта без ключа | `/api/np/warehouses` відповідав 503 | Тепер 200 `{enabled:false}` |
| Міграції | Посилання `items.product` і `reviews.product` на `products` ламали б збереження вбудованих товарів | Зняті в `0003` |

## Подключение Supabase и Notion

```bash
cd apps/web
# 1. Supabase: выполните supabase/migrations/0001_init.sql, затем 0002_catalog_items_journal.sql в SQL editor проекта, затем в .env.local:
#    SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY
npm run check:connections      # проверяет таблицы и базы
npm run supabase:seed          # загружает 15 трав и 6 семейств в Supabase
# 2. Notion: импорт docs/notion-import/*.csv (см. docs/NOTION.md), затем NOTION_TOKEN, NOTION_DB_SPECIES, NOTION_DB_FAMILIES
npm run sync:notion            # Notion -> JSON + Supabase
```
